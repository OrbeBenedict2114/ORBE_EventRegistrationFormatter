# Student Event Registration Formatter

## Project Overview
A Python-based command-line application designed to collect, clean, format, and display student event registration summaries. 
This project was developed incrementally across three versions to demonstrate progressive improvements in data handling, string manipulation, and date formatting.

## Version History
- **Version 1:** Initial version featuring basic input collection and direct output display.
- **Version 2:** Added string manipulation methods (`.strip()`, `.title()`, `.upper()`) to clean and standardize user text inputs.
- **Version 3:** Integrated Python's built-in `datetime` module to parse and render event dates in a clean, readable format.

## Features
- Interactive user prompts for student names, section, event details, and date.
- Automated cleaning of trailing whitespaces and inconsistent capitalization.
- Standardized date formatting using robust error handling.

## How to Run
1. Ensure Python 3.x is installed on your computer.
2. Open your terminal or command prompt in the project directory.
3. Run the script: `python main.py`
